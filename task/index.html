给 agent 的读法
1. 先按「状态」挑任务：待执行 / 待排期 可直接开工；待用户/owner 的先别动，等拍板。
2. 预计 token 是整任务消耗（读代码+实现+测试+返工一轮）的经验区间，不是承诺：契约/集成等 high 难度 150k–350k，一般实现 70k–180k，定点修复 30k–90k，运维轮次按次计。
3. 推荐模型 按难度与审查要求定：契约、集成、评测题、安全审查用强推理（Opus 级）；常规实现用 Sonnet 级；仓库原定 runner 为 codex 的用 GPT-5 Codex 级，且按仓库规则由另一家模型交叉审查；机械小活用 Haiku 级。
4. 仓库硬规则：分支+PR、不直推 main；不提交任何密钥；史实与数据必须有出处；IVY 任务的验收命令统一 make check T=<测试路径>，全离线。
