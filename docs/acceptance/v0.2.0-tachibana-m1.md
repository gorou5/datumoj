## 5. 遗留与说明

- **内阁府不支持条件请求**：同一文件每次返回的 ETag 不同（如 `"127d-65460b1988368"` 和 `"127d-65460b1987e2a"`，像是多台服务器各自计算），每次都重新下载约 100 个文件。内容哈希不变，不产生新版本，只多耗流量。
- **大阪市种子达到 200 页上限**：该栏目页面很多，`max_pages_per_seed` 是否放宽或改成更细的栏目，留给种子清单定稿（H2）时决定。
- **只有链接列表的页面记为解析失败**（第 3 次后 25 个）：符合 202 的规则（正文不足 100 字不算成功），不是故障。
- **内阁府 `joip_1st_8th_all.pdf`** 有一页超过本机 Ollama 嵌入模型的上下文长度，这一份向量暂缺，关键词检索不受影响。
- **PDF 的 `needs_ocr`**：多数 PDF 有 1 页（常是封面）文字不足 50 字被标为需要 OCR，属预期。
- 三个站点的利用规约见 `tests/fixtures/gov_web/README.md`；来源仍标 `internal_only`，没有扩大再分发权限。
- M3 的 H4（在 Claude Code 里注册 MCP 做真实问答）由人另行确认。
