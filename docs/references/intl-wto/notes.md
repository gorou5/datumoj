# 接口笔记：WTO Timeseries API

## 资料范围

本资料分别整理 WTO 网站一般版权页与 API 门户页；没有把两页合并成同一套数据许可条件。[仅读文档]

## 接口与访问

- API 门户称 Timeseries API 可程序化访问大量 WTO 统计指标；门户还称 Stats Portal 可交互检索 Timeseries 数据并带有 API query builder。[读过官方页面（2026-10-24）]
- 门户列出的时间序列范围包括货物贸易、服务贸易、市场准入关税、非关税信息及其他指标；未给出指标覆盖清单或字段细节。[读过官方页面（2026-10-24）]
- API 门户称开发者通过注册取得 API Key，并称 API 免费；具体 Key 权限、额度、过期或撤销行为没有说明。[读过官方页面（2026-10-24）]
- 门户提及自动生成的 API 文档和可直接交互的 API Console，但保存文本没有包含具体端点、参数、响应格式或示例。[读过官方页面（2026-10-24）]
- 每次查询数量、调用频率、IP 限流、封锁机制、批量下载边界、数据格式和更新周期均未在保存文本中说明。[待确认]
- 门户没有列出服务可用性、维护窗口或支持时限。[待确认]
- 一般版权页说明 WTO 网站资料的版权和许可，但未说明该文本是否管辖 Stats Portal 或 Timeseries API 数据。[待确认]
- 保存页面没有涉及云端模型处理、自动传送给模型服务或模型使用。[待确认]
