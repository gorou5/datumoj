# 每月勤劳统计资料的条款文字与未决事项

S22 是厚生劳动省网站自己的利用规约页，不是某一 e-Stat CSV 或 PDF 的文件级许可记录。e-Stat 条款记录已在 jp-estat-api 和 jp-estat-files 包中；本包没有重录第二份 e-Stat 条款。

## 1. 厚生劳动省网站规则文字

- 页面自称说明厚生劳动省首页内容的使用方式（S22；mhlw_chosakuken.txt:202-204）。其文字称，除另有标记外，内容归属于厚生劳动省；未显示权利标记时，页面指向公共数据利用规约第1.0版（PDL1.0）的条件（S22；mhlw_chosakuken.txt:203-204）。这句话是站点层面的条件文字，不确认本调查某一 CSV、PDF 或 e-Stat 下载文件是否属于其范围。
- 页面要求注明出处：「出典を記載してください。」（S22；mhlw_chosakuken.txt:207）。页面列出厚生劳动省网站及具体页面 URL 的出处示例（S22；mhlw_chosakuken.txt:208-210）。
- 页面要求在编辑加工时另外说明处理事实：「編集・加工等を行ったことを記載してください。」（S22；mhlw_chosakuken.txt:211）。并称不得以仿佛由国家或府省制作的方式发布加工内容（同上）。
- 页面列出组织或特定事业的标志、Logo、角色设计，以及明确标示适用其他规则的内容等例外（S22；mhlw_chosakuken.txt:217-219）。本包没有据此为具体附件分类。
- 详细 PDL1.0 正文未在本轮材料中单独捕获；页面的引用不用于补写其全部条件。

## 2. e-Stat 记录与交叉适用未决事项

- e-Stat 条款仍分别记录在 jp-estat-api 与 jp-estat-files 包中；本包只保留此指针，不创建第二份 e-Stat 条款记录。
- 厚生劳动省页面说明的是厚生劳动省首页内容；e-Stat 包的条款记录针对 e-Stat 页面。捕获文字没有说明某一从 e-Stat 下载的本调查 CSV/PDF 应适用哪一方条款，也没有逐文件列出权利标记。该问题为 NOT STATED（S22；mhlw_chosakuken.txt:203-219）。
- 维护者配置中的条款区块保持为维护者配置文字，不能替代官方站点页面，也不构成对某一数据文件的判断（M1；datumoj_plan_excerpt.md:38-48）。
- 本包不对文件可用范围、第三方权利、再分发或任何具体下载物作许可结论，也不判断本次或未来的数据获取是否获准。
