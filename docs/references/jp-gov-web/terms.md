本包没有逐一检查目标单页及附件（包括 PDF）的权利。各站点页面分别说明自己的站点级规则、条件与例外；是否有某一被抓取页面或 PDF 带有其他权利标记为 NOT STATED（S2；cao_rule.txt:9,13-14；S4；soumu_tyosaku.txt:127,141-146；S7；osaka_use_data.txt:58,68-80；S8；osaka_copyright.txt:94-99）。因此，本包不判断具体页面或文件的适用许可、再分发状态，也不判断该抓取行为是否获准。

## 3. 大阪市

### 大阪市自己的页面与规则

- S6 捕获正文显示页面题名、日期和著作权导航（S6；osaka_site_policy.txt:50-56）；具体规则分别记录在 S7 与 S8。
- S7 明说自己是「著作権」の概要版（S7；osaka_use_data.txt:53），并写明页面若标有 CC-BY 以外的许可或其他规则，应遵循页面所写（S7；osaka_use_data.txt:57-58）。
- S7 区分文本、数值与附件；对许可标记和无标记文件分别说明（S7；osaka_use_data.txt:61-80）。无标记文件的处理状态为：「利用可否については、ご自身の責任において確認してください。」（S7；osaka_use_data.txt:78-80）。
- S7 说明部分文章可能包含第三方权利，且权利部分可能已标出也可能未标出（S7；osaka_use_data.txt:94-101）；页面要求对需确认内容向页面作成者确认（S7；osaka_use_data.txt:104-105）。
- S8 列有第三方著作权、肖像权、公众形象权等，并把是否明确标示交由使用者确认（S8；osaka_copyright.txt:70-74）。
- S8 规定，除明确标明已完成权利处理的内容外，使用者应自行取得第三方许可；通过 API 等从外部数据库取得的内容应遵从提供方利用条件（S8；osaka_copyright.txt:71,73）。S7 还说明，部分第三方内容可能仅获准用于大阪市网站展示（S7；osaka_use_data.txt:96）。此处不判断任何目标页面或 PDF 的许可。
- S8 将组织或项目标志、Logo、角色设计，以及明示适用其他利用规则的内容列为排除项（S8；osaka_copyright.txt:77-81）。

### 图片、附件和文件标记

- S8 单独列出页面显示或附加的图片、Excel 等文件（S8；osaka_copyright.txt:92-96）。对没有许可标记的图片或附件，页面写明「無断での使用や転載を禁じます。」（S8；osaka_copyright.txt:97-99）；本包没有检查任何目标 PDF 是否属于此情形。
- S7 的概要页写明：如果某个附件没有许可标记，页面要求自行确认（S7；osaka_use_data.txt:78-80）。本包不把概要页或完整规则推广到未经逐项查看的具体 PDF。
- S8 说明其规则与 CC BY 兼容，并将该说明限定在规则适用内容：「本利用ルールが適用されるコンテンツはCC BYに従うことでも利用することができます。」（S8；osaka_copyright.txt:90-91）。这句话不确认任一目标页面或文件属于其适用范围。
- S8 记载本利用规则依政府标准利用规约第 2.0 版制定（S8；osaka_copyright.txt:88-91）。大阪市记录保留在本节，不套用内閣府或総務省的 PDL1.0 文字。
