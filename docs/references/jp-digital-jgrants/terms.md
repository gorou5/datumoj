## 3. 门户规约与 API 返回数据范围问题

S1 第 3 条说 Web-API 规约适用于本功能的使用。（F7；S1；api_terms.txt:20, api_terms.txt:21）原文：「本利用規約は、本機能提供者が提供する本機能の利用に対して適用されます。」（S1；api_terms.txt:21）

S3 是门户服务规约；它把数字厅网站定义为域名为 jgrants-portal.go.jp 的网站。（S3；portal_stipulation_excerpt.txt:21, portal_stipulation_excerpt.txt:25）S3 第 14 条第 3 项第 2 号对服务提供的内容写有不得进行「複製、改変、編集、頒布等」（S3；portal_stipulation_excerpt.txt:37），并以「行わないこと。」结束该项。（S3；portal_stipulation_excerpt.txt:37）第 29 条第 3 项称规约与 CC BY 4.0 兼容，并称适用该规约的内容也可依 CC BY 使用；原文片段：「CC BYに従うことでも利用することができます」（S3；portal_stipulation_excerpt.txt:64）。

- S3 第 14 条第 2 项：利用者使用本服务，并不意味着已获得本服务提供者知识产权的利用许诺。（S3；portal_stipulation_excerpt.txt:32）原文片段：「利用許諾を受けたことを意味するものではありません」（S3；portal_stipulation_excerpt.txt:32）。

- S3 第 14 条第 3 项第 3 号：无论有无营利目的，不得向第三方出借、转让或设定担保。（S3；portal_stipulation_excerpt.txt:38）原文片段：「第三者に貸与し、譲渡し、又は担保の設定をしないこと」（S3；portal_stipulation_excerpt.txt:38）。
