## 1. 适用关系

- e-Gov 利用规约页把适用范围写成 e-gov.go.jp 及其子域名上的信息；法令API 的主机 laws.e-gov.go.jp 是 e-gov.go.jp 的子域名，因此落在这份规约的范围内。（摘要，非引用；https://www.e-gov.go.jp/terms ；核对：2026-10-19） [读过官方页面（2026-10-19）] 〔证据:S6〕
- 同一页写明这些信息的著作权除特别注明外归数字厅，并写明默认适用的许可：「権利表記の記載がない限り「公共データ利用規約（第1.0版）」（PDL1.0）が適用されます。」（原文：https://www.e-gov.go.jp/terms ；核对：2026-10-19） [读过官方页面（2026-10-19）] 〔证据:S6〕
- 该页的另纸列出适用其他规则的内容：logo、e-Gov 帐号服务利用规约、e-Gov 电子申请服务利用规约。法令数据不在这个列表里。（摘要，非引用；同上链接与核对日期） [读过官方页面（2026-10-19）] 〔证据:S6，https://www.e-gov.go.jp/terms〕
- API 的技术规格（定义文件）里没有任何许可、署名或使用条件的条文，只有技术规格；所以权利关系只能从上面两份文件读。（摘要，非引用；https://laws.e-gov.go.jp/api/2/swagger-ui/lawapi-v2.yaml ；核对：2026-10-20） [读过官方页面（2026-10-20）] 〔证据:S9，https://www.digital.go.jp/resources/open_data/public_data_license_v1.0〕

## 2. 商用

- e-Gov 利用规约页上没有出现“商用”字样：该页对商用既没有写可以，也没有写禁止 → 该页范围 NOT_FOUND。（核对：2026-10-19，https://www.e-gov.go.jp/terms） [读过官方页面（2026-10-19）] 〔证据:S6〕
- 该页指定适用的 PDL1.0 正文写明：「商用利用も可能です。」（原文：https://www.digital.go.jp/resources/open_data/public_data_license_v1.0 ；核对：2026-10-20） [读过官方页面（2026-10-20）] 〔证据:S9〕
- 这句话紧接在一个长句之后，那个长句把范围限定为“除适用其他利用规则的内容外”，并要求按 PDL1.0 第 1.1 至 1.7 条的规则利用。也就是说，“可以商用”以“属于本内容、并遵守本规则”为前提。（摘要，非引用；同上链接与核对日期） [读过官方页面（2026-10-20）] 〔证据:S9，https://www.digital.go.jp/resources/open_data/public_data_license_v1.0〕
- 因此，按许可文本的字面：商用可以。这是对许可文本的摘录与摘要，不是法律意见。（同上） [推测] 〔证据:S9，https://www.digital.go.jp/resources/open_data/public_data_license_v1.0〕

## 3. 署名（出典）与加工时的追加记载

- 出典记载是义务句：「コンテンツを利用する際は出典を記載してください。」（原文：https://www.e-gov.go.jp/terms ；核对：2026-10-19） [读过官方页面（2026-10-19）] 〔证据:S6〕
- e-Gov 给的记载例：「出典：e-Govポータル （https://www.e-gov.go.jp）」（原文：https://www.e-gov.go.jp/terms ；核对：2026-10-19） [读过官方页面（2026-10-19）] 〔证据:S6〕
- 该页另给一个针对具体页面的例子，形式是：出典记号＋（引号内的标题）＋（e-Govパブリックコメント）＋（当该页面的 URL）＋（○年○月○日に利用）。（摘要，非引用；同上链接与核对日期） [读过官方页面（2026-10-19）] 〔证据:S6，https://www.e-gov.go.jp/terms〕
- 编辑、加工后利用时，要在出典之外另行写明做过加工以及加工的主体：「本コンテンツを編集・加工等して利用する場合は、上記出典とは別に、編集・加工等を行ったこと及びその主体を記載してください。」（原文：https://www.e-gov.go.jp/terms ；核对：2026-10-19） [读过官方页面（2026-10-19）] 〔证据:S6〕
- 该页还禁止把加工过的信息说成是国家或省厅等作成、未经加工的样子。（摘要，非引用；同上链接与核对日期） [读过官方页面（2026-10-19）] 〔证据:S6，https://www.e-gov.go.jp/terms〕
- 针对 API 响应本身的专用署名文案：NOT_FOUND。e-Gov 页给的例子是门户级与页面级的，没有一条是为机器读取的法令文本写的；PDL1.0 也没有 API 专用文案。（核对：2026-10-19 / 2026-10-20，上述两个链接） [读过官方页面（2026-10-20）] 〔证据:S6，https://www.e-gov.go.jp/terms〕 〔证据:S9，https://www.digital.go.jp/resources/open_data/public_data_license_v1.0〕

## 4. 第三方权利

- PDL1.0 写明内容里可能有第三方拥有著作权等权利的部分；除明确标注权利已处理的外，利用者要自己负责取得该第三方的许可。（摘要，非引用；https://www.digital.go.jp/resources/open_data/public_data_license_v1.0 ；核对：2026-10-20） [读过官方页面（2026-10-20）] 〔证据:S9〕
- 同一节还写：「外部データベース等とのAPI（Application Programming Interface）連携等により取得しているコンテンツについては、その提供元の利用条件に従ってください。」（原文：同上链接；核对：2026-10-20） [读过官方页面（2026-10-20）] 〔证据:S9，https://laws.e-gov.go.jp/api/2/swagger-ui/lawapi-v2.yaml〕
- 法令API 本身是 e-Gov 自己提供的接口，不是“从外部数据库取得的内容”；这一句对该 API 是否适用，证据里没有说明 → UNCLEAR。（同上） [推测] 〔证据:S9，https://laws.e-gov.go.jp/api/2/swagger-ui/lawapi-v2.yaml〕
- 定义文件没有说明法令正文是否含第三方权利（例如附图中的照片、地图）；保存的来源证据不能确认该点 → NOT_FOUND。 [读过官方页面（2026-10-20）] 〔证据:S9，https://www.digital.go.jp/resources/open_data/public_data_license_v1.0〕

## 5. 复制、再分发与缓存

- PDL1.0 把可用的行为列举为「複製、公衆送信、翻訳・変形等の翻案等」——复制与公众传播都在其中，且写明可以自由利用、可以商用（见第 2 节）。（原文：https://www.digital.go.jp/resources/open_data/public_data_license_v1.0 ；核对：2026-10-20） [读过官方页面（2026-10-20）] 〔证据:S9〕
- 因此，把响应保存下来并向公众提供，在 PDL1.0 的文本里有依据，条件是第 3 节的出典记载与第 4 节的第三方权利条款。（摘要，非引用；同上） [推测] 〔证据:S9，https://www.digital.go.jp/resources/open_data/public_data_license_v1.0〕
- e-Gov 利用规约页本身没有再写“再分发”的条款 → 该页范围 NOT_FOUND；它只是把 PDL1.0 指定为默认规则。（核对：2026-10-19，https://www.e-gov.go.jp/terms） [读过官方页面（2026-10-19）] 〔证据:S6〕
- 缓存与保存期限：PDL1.0 没有设期限，但同时写明「本コンテンツは、予告なく変更、移転、削除等が行われることがあります。」——缓存可能悄悄与线上文本分叉。（原文：同上 PDL1.0 链接；核对：2026-10-20） [读过官方页面（2026-10-20）] 〔证据:S9，https://www.digital.go.jp/resources/open_data/public_data_license_v1.0〕
- 定义文件与门户页都没有写法令数据的删除规则或保留期限 → NOT_FOUND。（核对：2026-10-20 / 2026-10-19） [读过官方页面（2026-10-20）] 〔证据:S6，https://www.e-gov.go.jp/terms〕 〔证据:S9，https://laws.e-gov.go.jp/api/2/swagger-ui/lawapi-v2.yaml〕

## 7. 保留与更新

- 内容可能不预告地变更、迁移、删除（PDL1.0 第 1.6 条，引文见第 5 节）。→ 缓存要能察觉分叉。 [读过官方页面（2026-10-20）] 〔证据:S9，https://www.digital.go.jp/resources/open_data/public_data_license_v1.0〕

## 8. 判断：本资料为什么收录样本

判断规则（机械执行）：只有当保存下来的证据（本节的规约页、许可页与定义文件）显示 e-Gov 的内容是在允许再分发的许可下提供的，并且能逐字引用该表述时，才把两个真实样本放进 `samples/`；证据不清楚或有矛盾时不放，只在 notes.md 写获取方法。 [仅读文档] 〔证据:S1，https://www.e-gov.go.jp/terms；https://www.digital.go.jp/resources/open_data/public_data_license_v1.0〕
