# BODIK ODCS（jp-bodik）利用规约与待确认事项

S1-S7 的完整释义见 notes.md 开头的证据标签列表。

## 1. 适用条款与商业用途

- BODIK ODCS 页面将数据集利用规约交由各自治体决定，没有给出适用于所有目录元数据的统一许可。（读过官方页面（2026-10-20））〔证据:S1〕

> 「BODIK ODCSに掲載されているデータセットの利用規約は、各自治体が定める利用規約に依存します。」

> 原文链接：https://odcs.bodik.jp/about/；核对日期：2026-10-20。（读过官方页面（2026-10-20））〔证据:S1〕

- 所查关于页面和开发者页面没有给出统一商业使用允许或禁止条款；具体数据集的商业使用须查其对应自治体规约与许可。（仅读文档）〔证据:S1〕〔证据:S2〕
- 一次 package_show 响应显示 dataset 级 license_id 为 cc-by、标题为 Creative Commons Attribution；保存页面未提供该许可文本，因此本资料不据标识作商业使用结论。（真实请求验证过）〔证据:S7〕

## 2. 署名与第三方权利

- 所查 BODIK 页面未规定一条全站通用署名文案，也未给出 API 响应专用署名要求。（仅读文档）〔证据:S1〕〔证据:S2〕
- BODIK 页面称数据集规约由各自治体规定；第三方权利及具体署名要求需按对应数据集的规约核对。（读过官方页面（2026-10-20））〔证据:S1〕
- 对自治体网站或其他外部网站托管的资源文件，门户页面没有说明是否可按门户条款抓取，状态为待确认。（仅读文档）〔证据:S1〕〔证据:S2〕

## 3. 保存、再分发与自动读取

- 所查关于页面和开发者页面没有给出平台级保存期限、缓存规则、目录元数据再分发许可或衍生作品要求。（仅读文档）〔证据:S1〕〔证据:S2〕
- 开发者页面说明 CKAN API 可读取数据集元数据，并提供 DataStore 表格内容的调用示例。（读过官方页面（2026-10-20））〔证据:S2〕
- 上述 API 说明不是商业使用或再分发许可；目录元数据及各数据集文件的再分发状态均待确认。（仅读文档）〔证据:S1〕〔证据:S2〕
- 关于页面和开发者页面没有给出统一的请求频率或自动读取速率；robots.txt 的分组延迟规则见 notes.md。（仅读文档）〔证据:S2〕〔证据:S4〕〔证据:S5〕

## 4. 许可字段与真实响应样本决定

- 所读数据集页面显示 Creative Commons 表示。（读过官方页面（2026-10-20））〔证据:S6〕
- 一次 package_show 响应显示 dataset 级 cc-by 标识，而 13 个 resource 的 license_id 均为 null。（真实请求验证过）〔证据:S7〕
- 一条响应不能确定 resource.license_id 为 null 的含义，也不能代表其他数据集；逐资源许可及其与 dataset 级许可的关系待确认。（仅读文档）〔证据:S7〕
- 本资料不附带真实响应：页面未证明目录元数据可再分发；响应的 maintainer 字段有一个电话形状值；所示许可标识的许可正文没有随证据提供。（仅读文档）〔证据:S1〕〔证据:S7〕
- 文件体积低于样本门槛，但上述许可与隐私条件未全部满足，因此可否再分发仍为待确认。（真实请求验证过）〔证据:S7〕
