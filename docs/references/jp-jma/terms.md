- feed 入口为 PULL；PUSH 已结束。采集设计应使用页面列出的 feed URL，并留存原始响应字节。（推测；S7a）

- 任何公开再利用都应按气象厅出典规则注明来源；处理或变换后还要说明处理事实，不得让处理后的数据看似气象厅原始内容。（读过官方页面（2026-10-20）；S9）
- 是否可重新发布具体 XML 或平年値文件，仍需按页面利用说明、文件权利标记及 XML 留意事项 PDF 逐项确认；本资料不作法律结论。（仅读文档；S4）
- normals 页面和 XML 服务页的 robots.txt 请求均返回 404 HTML；这不是授权，也不是禁止声明。（真实请求验证过；S8）
