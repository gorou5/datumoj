## A. 防灾信息 XML Atom feed

### 入口和 feed 清单

- XML/PULL 说明入口为 https://xml.kishou.go.jp/xmlpull.html；feed URL 前缀为 https://www.data.jma.go.jp/developer/xml/feed/。（读过官方页面（2026-10-20）；S7a、S9）
- 已记录的四类 feed 文件名为 regular.xml、extra.xml、eqvol.xml、other.xml；对应长周期文件名为 regular_l.xml、extra_l.xml、eqvol_l.xml、other_l.xml。资料把不带 _l 的列为高频 feed、_l 列为长周期 feed。（读过官方页面（2026-10-20）；S7a、S9）
- 以上八个 feed 地址在本次来源记录中标为“referenced only”；没有读取 feed 响应正文，故不能把地址引用当作已取得 feed 样本。（仅读文档；S5、S9）

### 更新、保留与信息识别

- 文档记载高频 feed 每分钟更新，长周期 feed 每小时更新。（仅读文档；S7a）
- FAQ 记载高频 feed 当前约保留 10 分钟、长周期 feed 当前约保留过去 7 天；页面同时说明不保证保存该期间的全部电文，且今后可能不预告变更。（读过官方页面（2026-10-20）；S9）
- FAQ 说明同一信息单位可由 Title、EditorialOffice、Status 三项识别；部分电文还要结合 EventID。该单位中 DateTime 最新的电文有效。（读过官方页面（2026-10-20）；S9）
- Serial 用于表示信息单位中的发布顺序，但气象厅不保证它连续或唯一；资料也提及订正、取消电文。（读过官方页面（2026-10-20）；S9）
- 以上是 FAQ 对信息单位的说明，不等同于 Atom entry 的去重键。Atom id、updated、link 的具体路径或组合规则未在已保存页面中确认。（读过官方页面（2026-10-20）；S9）

### 传输与 XML 处理边界

- 气象厅说明其主页公开的该 XML 电文只以 PULL 方式提供；主页 PUSH 服务已于 2020-09-01 结束。页面称无需注册即可使用。（读过官方页面（2026-10-20）；S9）
- 说明页提到自动处理可按用途使用，但要求先阅读 XML 利用留意事项 PDF；该 PDF 在本次资料中只有链接，没有阅读其内容。（读过官方页面（2026-10-20）；S9）
- 说明页称，若对公开 XML URL 的下载量达到每日 10 GB 以上，会阻断来源 IP。已核对页面没有给出每秒请求数上限；不要把本资料的采样节奏写成气象厅限制。（读过官方页面（2026-10-20）；S9）
- FAQ 表示管理部与标题部在电文间具有共同结构，内容部随电文类型而异；各标签的具体运用仍需查运用表和各电文说明。（读过官方页面（2026-10-20）；S9）
- feed XML 响应的字符编码、Atom/XML namespace、DTD 与外部实体处理要求、最大响应体大小、特定可选 Duration 字段的行为，均未由已读取页面或真实 feed 响应确认。（仅读文档；S3、S7a、S9）
- 本次证据没有真实 feed XML 文件。后续自行采集时，可对一个已列出的 feed 文件发起 GET，例如 https://www.data.jma.go.jp/developer/xml/feed/<feed-filename>；占位符应替换为上述文件名，页面没有说明额外 query 参数。（推测；S5、S7a）
- 自行采集建议最多每秒 1 个请求，并保留响应原始字节，同时记录请求 URL、取得时间、HTTP 状态和 SHA-256。每秒 1 次是本资料提出的保守采样建议，不是气象厅公布的请求速率；不要重复下载已经取得的文件。（推测；S7a、S8）

## B. 平年値下载与站点资料

### 下载入口、URL 形式与版本

- 官方入口页为 https://www.data.jma.go.jp/stats/data/mdrr/normal/index.html；数据目录为 https://www.data.jma.go.jp/stats/data/mdrr/normal/2020/data/，说明目录为 https://www.data.jma.go.jp/stats/data/mdrr/normal/2020/doc/。（读过官方页面（2026-10-20）；S2、S9）
- 地上气象观测月别及年值 CSV 位于 normal_surface.zip；档案内路径为 normal_surface/monthly/nml_sfc_m_<station-number>.csv，文件名中的地点编号为 5 位。每条记录包含 12 个月并带年值字段；未发现独立的年值文件名。（仅读文档；S2）
- アメダス月别及年值 CSV 位于 normal_amedas_monthly.zip；档案内路径为 normal_amedas/monthly/area@@/nml_amd_m_@@***.csv，其中 @@ 为区域编号、*** 为观测所编号。记录同时含月值和年值。（仅读文档；S2）
- 两个 ZIP 的公开入口形式分别为 https://www.data.jma.go.jp/stats/data/mdrr/normal/2020/data/normal_surface.zip 与 https://www.data.jma.go.jp/stats/data/mdrr/normal/2020/data/normal_amedas_monthly.zip。（仅读文档；S2、S9）
- 地点索引的 ZIP 是 https://www.data.jma.go.jp/stats/data/mdrr/normal/2020/data/amedas_station_index.zip，内含 amedas_station_index.csv。（仅读文档；S2）
- 地上气象观测站的月・年平年値网页形式为 https://www.data.jma.go.jp/stats/etrn/view/nml_sfc_ym.php?prec_no=<2-digit>&block_no=<5-digit>&year=&month=&day=&view=；prec_no 与 block_no 的编号体系不可与アメダス地点编号混用。（仅读文档；S2）
- 下载页列出的地上气象观测 ZIP 约 20.6 MB，アメダス月・年 ZIP 约 3.06 MB；站点索引 ZIP 约 40 KB。较大档案在压缩包内的布局来自格式资料，没有在本次材料中重新解压验证。（读过官方页面（2026-10-20）；S2、S9）

### 版本、文件结构与字段

- 下载页现列 2020 年平年値第 5 版，统计期间为 1991–2020，页面记载利用开始日为 2025-05-21；页面另有旧版更正历史，但没有给出今后的固定更新周期。（读过官方页面（2026-10-20）；S9）
- 地上月・年 CSV 的记录长度为 143 字节（不含换行），数据类型为 11，包含地点号、要素编号、年份 / 统计期间字段、参考平年值、1–12 月值及年值；要素编号为 4 字符，数值字段带 RMK 标记。（仅读文档；S2）
- アメダス月・年 CSV 的记录长度也为 143 字节（不含换行），数据类型为 21；要素编号为 5 字符。不能把地上观测格式的固定列偏移直接套用到アメダス格式。（仅读文档；S2）
- 地上观测月・年格式列出的 RMK 值包括 0（无统计值）、5（参考平年值 / 无现象）、6（平年值 / 无现象）、7（参考平年值）、8（平年值）；参考值不能用于平年值差或比率计算。（仅读文档；S2）
- アメダス月・年格式资料列出的 RMK 范围为 0 与 8。完整要素编号表和每一类站点具体出现的要素，应以格式文件对应表格为准，不作外推。（仅读文档；S2）
- 站点索引含地点编号、汉字 / 假名 / 罗马字站名、纬度与经度的度分字段、海拔、风速仪高度及降水、风、气温、日照、积雪等观测标记。格式表记录其 header 与数据行字节宽度；索引 CSV 的 CP932 编码由真实取得文件验证。（真实请求验证过；S2、S4）
- アメダス站点观测标记中，1 表示观测、0 表示未观测；日照标记 2 表示卫星推定值。（仅读文档；S2）
- 大阪地上观测月・年 HTML 页面显示 1–12 月及年值、1991–2020 期间和 18 项气候要素；缺值显示为 ---，@ 表示参考值，不能用于平年差或比率。（真实请求验证过；S2、S4、S6）
- HTML 表中要素包括本站气压、海平面气压、降水量、平均 / 最高 / 最低气温、水汽压、相对湿度、风速、最多风向、日照、太阳辐射、降雪深、最深积雪、云量及降雪 / 雾 / 雷日数。（真实请求验证过；S2、S6）
- amedas_station_index.csv 的编码为 CP932；月・年 normals CSV 的编码在格式 PDF 中没有说明。不得把索引编码外推到 normals CSV。（真实请求验证过；S2、S4）
- 可作资料日期的来源字段是 1991–2020 统计期间及行内月 / 年维度；文件下载时间只是取得时间，不代表平年值统计日期。（仅读文档；S2、S6、S9）
