# 利用规约与采集注意事项：OECD Data

## 条款来源

- [OECD Terms and Conditions](https://www.oecd.org/en/about/terms-conditions.html) 第 3 节 Data，包含 Permitted Use、Availability of Data 和 OECD APIs 三部分。[读过官方页面（2026-10-24）]
- 条款说明具体数据可能受额外条件限制，是否属于 OECD 或第三方所有也须看相应数据 metadata；本节不是逐数据集的权利确认。[读过官方页面（2026-10-24）]

## 条款主题

- **复制、改编、再分发与商业用途**：在没有额外限制时，第 3 节列出提取、下载、复制、改编、打印、分发、分享和嵌入，并包括商业用途；适用前须核对数据 metadata 和第三方权利。[读过官方页面（2026-10-24）]
- **署名要求**：优先使用相关数据自带 citation；若没有特定 citation，页面给出的格式为「OECD (year), (dataset name),(data source) DOI or URL (accessed on (date)).」。[读过官方页面（2026-10-24）]
- **再许可**：分享或许可基于数据制作的作品时，须在再许可中纳入相同 acknowledgment 要求，并要求后续再许可继续这样做；页面原文为「include the same acknowledgment requirement in any sub-licenses that you grant」。[读过官方页面（2026-10-24）]
- **第三方权利与例外**：使用者须从 metadata 或 source tab 检查第三方所有权和额外限制，并在纳入工作前联系数据所有者取得所需许可；OECD 不保证拥有或控制所有数据权利。[读过官方页面（2026-10-24）]
- **自动化访问、批量下载、限速或封锁**：条款允许数据提取、下载和 API 访问，但没有给固定配额；OECD 保留调整单次查询量及指定时段查询数量的权利，并可限制或暂停 IP 访问。[读过官方页面（2026-10-24）]
- **API 条款与 Key**：API 按 as-is 提供，使用风险由使用者承担，页面不承诺支持；登记资料是自愿的，Key 是否需要没有说明。[读过官方页面（2026-10-24）]
- **变更与可用性**：数据可被移除、格式可改变，API 可被暂停或终止；条款可能更新，页面要求使用者定期查看变化。[读过官方页面（2026-10-24）]
- **云端模型处理**：未见云端模型、AI/model 使用或第三方模型处理的专门条款；一般用途说明没有明确解决 cloud_model_ok。[待确认]

## 对 DATUMOJ 0.4 许可闸门的含义

- 第 3 节的一般用途条款以无额外限制为前提；逐数据集的 metadata 和第三方权利仍未确认，不能将一般条款直接推广到所有 OECD 数据。[读过官方页面（2026-10-24）]
- 保存页面没有明确涉及云端模型处理；cloud_model_ok 无明确依据，按计划缺省 false。[待确认]
