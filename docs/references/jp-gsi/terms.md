## 1. 国土地理院内容规约与 PDL1.0

国土地理院内容利用规约说，除另有说明外，其网站内容适用公共数据利用规约（第1.0版）：（读过官方页面（2026-10-20）；S2）

> 「本サイトのコンテンツには特段の記載が無い限り公共データ利用規約（第1.0 版）（PDL1.0）が適用されています。」
原文链接：https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html；核对日期：2026-10-20。（读过官方页面（2026-10-20）；S2）

公共数据利用规约（第1.0版）摘录说，适用该规约的内容可以商业利用；这句话本身不能确认標高 API 输出是否属于其适用范围：（仅读文档；S3）

> 「商用利用も可能です。」
原文链接：https://www.digital.go.jp/resources/open_data/public_data_license_v1.0；核对日期：2026-10-20。（仅读文档；S3）
该句在本次保存的官方页面中未能直接核对，仅见于对该规约的摘录；上下文以官方原文为准。（仅读文档；S3）

- 国土地理院规约另列第三方权利与个别法令限制；使用者仍须确认具体内容的权利与适用规则。（读过官方页面（2026-10-20）；S2、S3）
- 標高 API 说明页没有许可、商业利用或署名句；保存页面未说明 API 服务主机与「本サイト」范围的关系。（读过官方页面（2026-10-20）；S1、S2）
- 因此，PDL1.0 对适用内容的商业利用表述，并未单独决定该 API 响应的商业接受；商业接受状态为待确认。（仅读文档；S1、S2、S3）

## 3. 测量法页面说了什么

- 测量法官方文本第九条将「測量成果」写作该次测量最终目的所得的结果；第二十九条与第三十条分别涉及基本测量成果的复制及用于其他测量，第四十三条与第四十四条涉及公共测量成果的复制及使用。（仅读文档；S4）
- 国土地理院利用规约提示部分内容受个别法令限制，并指向基本测量成果复制、使用的申请；公共测量成果的利用需由取得该成果的测量计划机构承认。（读过官方页面（2026-10-20）；S2）
- 国土地理院手续页列出基本测量成果种类、非测量成果示例，并区分测量法第二十九条复制与第三十条使用的手续场景。（读过官方页面（2026-10-20）；S5）
- 申請页面列出的在线窗口涉及测量法第二十九条、第三十条、第四十三条与第四十四条；该页面没有说这些条文是否适用于標高 API 的输出。（读过官方页面（2026-10-20）；S6）
- 地理院タイル页面说明不同瓦片类别的署名与手续条件，并单列標高タイル产品；该说明没有对標高 API 返回的单点数值作分类。（读过官方页面（2026-10-20）；S7）
- 已核对的 API 页面、规约页面、手续页面与测量法文本均未决定该 API 数值是否属于测量成果；此项为 UNCLEAR，待 Owner 与法务确认，不在本资料中作法律结论。（仅读文档；S1、S2、S4、S5、S6、S7）
