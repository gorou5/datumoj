## 1. 请求形状

- API 文档列出的 HTTPS endpoint 为 `https://cyberjapandata2.gsi.go.jp/general/dem/scripts/getelevation.php`；页面提供以经纬度为 query 参数的请求示例。（读过官方页面（2026-10-20）；S1）
- 请求形状示意：`https://cyberjapandata2.gsi.go.jp/general/dem/scripts/getelevation.php?lon=<decimal-degrees>&lat=<decimal-degrees>&outtype=JSON`；尖括号内容为类型占位，不是实际请求值。（读过官方页面（2026-10-20）；S1）
- `lon` 与 `lat` 均须提供，值为十进制度数；页面没有说明允许范围。（读过官方页面（2026-10-20）；S1）
- `callback` 与 `outtype` 二选一；`outtype=JSON` 返回 JSON，不能同时提供两个参数。（读过官方页面（2026-10-20）；S1）
- 文档只列经度、纬度与输出形式三个参数，未列出 Key 参数。（读过官方页面（2026-10-20）；S1）
- 保存的两次请求记录没有 Key。（真实请求验证过；S10）
- 页面没有列出批量经纬度形式；现有请求形状是一组坐标对应一个结果。（仅读文档；S1、S10）

## 2. 响应字段与数据形状

- 响应字段为 `elevation` 与 `hsrc`；类型示意：`{"elevation": <number | "-----">, "hsrc": <string>}`，占位符只说明值形状。（读过官方页面（2026-10-20）；S1）
- 文档说明出错时 `elevation` 与 `hsrc` 返回字符串 `-----`。（读过官方页面（2026-10-20）；S1）
- 两次真实请求验证到：成功响应中的 `elevation` 为数字类型，无数据响应中的 `elevation` 为字符串标记。（真实请求验证过；S10）
- `hsrc` 可能为 `1m（レーザ）`、`5m（レーザ）`、`5m（写真測量）`、`5m（写真測量5C）` 或 `10m`；这些是页面列出的来源类别。（读过官方页面（2026-10-20）；S1）
- 页面把 1m 与 5m 类别的标高小数位列为 0.1m，把 10m 类别列到 1m 位；`hsrc` 是来源类别，不是日期字段。（读过官方页面（2026-10-20）；S1）
- 页面称服务返回该位置可用的最高精度 `hsrc` 值；调用者不能在文档所列参数中选择另一精度类别。（读过官方页面（2026-10-20）；S1）
- 两种真实请求的响应只显示 `elevation` 与 `hsrc`，没有数据日期、版次、网格版本或调查年份；不得以请求时间替代数据日期。（真实请求验证过；S10）
- 经纬度基准与垂直基准未由已读 API 页面说明；此处不把坐标或标高解释成特定基准。（仅读文档；S1）

## 4. 与 DATUMOJ 计划的对照

- 保存的两种响应均无数据日期字段；请求时间不得替代数据日期。（真实请求验证过；S10）
- API 说明页未提供数据日期字段。（读过官方页面（2026-10-20）；S1）
- API 页面未将该响应分类；国土地理院手续页面未提及该 API。（读过官方页面（2026-10-20）；S1、S5）
- DATUMOJ 项目讨论中把该来源标为 `no_data_date`，且把许可与测量法分类列为未决（来自该项目的讨论，原文未随本包提交）。（推测；S1、S5、S10）
- 地理院タイル页面对特定瓦片的实时调用及署名说明只针对瓦片；该页面没有说明服务器返回的单点 API 数值应作相同分类。（读过官方页面（2026-10-20）；S7）
- 基盤地図情報网站介绍基本项目与部分数值标高模型的下载及显示方法；该页未提及標高 API 或该 API 的利用规约。（读过官方页面（2026-10-20）；S8）
