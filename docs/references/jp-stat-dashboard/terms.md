## 4. 样本再分发决定

本包不附 `samples/`。机械判定结果：条件 (a) 仅部分满足——统计ダッシュボード内容声明 PDL1.0，但规约明确要求外部 API 内容遵守提供方条件；条件 (b) 无法确认——两份真实 JSON 的调查名称都显示为 `国勢調査／人口推計`，没有指明该两条系列的权利主体或逐系列再分发许可。S1/S7 记载一些系列可能来自 ILOSTAT/SSDS 且受上游条件约束，但未将这两份样例绑定到具体第三方来源，也未提供对应来源的再分发确认。因此排除两个样例及其文件；README 按“部分 / 按指标核对”标识。[真实请求验证过｜S4；仅读文档｜S1,S7,S9,S10]

两份来源文件只用于本地隐私/凭证扫描和字段核对，不随包复制。无权利确认时不以官方入口、公开可获取或 PDL1.0 的一般声明替代每条外部来源系列的确认。[真实请求验证过｜S4；仅读文档｜S1,S7,S9]

## 5. 对采集方案的直接影响

- 取得 API 派生公开服务时展示 API 页面指定的完整信用文字；对编辑/加工内容另外说明处理行为与主体。[读过官方页面（2026-10-20）｜S9]
- 对每条系列保留 `STAT_NAME` / 来源调查等原始元信息；识别到外部提供方时记录其来源及相应条件。未确定来源或条件的系列标作待核验，不用站点级 PDL1.0 宣称已清权。[真实请求验证过｜S4；仅读文档｜S1,S7,S9,S10]
- 未见公开的 QPS 数值；请求安排应避免造成短时间大量访问或妨碍系统。本包提供的每秒最多一次建议是保守操作建议，不是官方公布配额。[读过官方页面（2026-10-20）｜S9；仅读文档｜S7；推测｜S9]
- 本次 robots.txt 路径返回 404 HTML 页面；不能由此推导 crawler 路径许可。执行前仍应遵守 API 页面使用条件并低频调用。[读过官方页面（2026-10-20）｜S8,S9]
- 规约允许内容后续更新、移动或删除；证据没有给出 API 数据 TTL 或系列版本保存期。采集记录应附抓取时间与源响应，不能假定旧值将永久保留。[读过官方页面（2026-10-20）｜S9；仅读文档｜S7,S10；推测｜S9]
