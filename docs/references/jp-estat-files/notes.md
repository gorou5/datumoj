## 1. 范围与入口

- 本资料整理 e-Stat 统计表文件检索与下载页面的可见信息；没有对文件下载发出真实请求。（仅读文档；S2）
- 文件检索入口为 <https://www.e-stat.go.jp/stat-search/files>。（读过官方页面（2026-10-20）；S2）
- e-Stat API v3 是单独来源（来源 ID jp-estat-api），不在本资料范围内。（仅读文档；S4）
- 检索页可切换政府统计、数据集一览与数据集三种检索对象；数据集对象覆盖单个文件与数据库内容。（读过官方页面（2026-10-20）；S2）
- 检索选项包括按提供分类、标题等元信息查找，以及查找数据库或文件内的集计项目、项目说明。（读过官方页面（2026-10-20）；S2）
- 页面说明数据集一览按提供分类、提供周期、调查年月归组；这些是页面描述的分组信息，不等同于已确认的文件行日期字段。（读过官方页面（2026-10-20）；S2）
- 页面列出的表格格式筛选项包括 EXCEL、CSV、PDF、XML、EXCEL 浏览用与 DB；该列表不证明每个表都提供所有格式。（读过官方页面（2026-10-20）；S2）
- 页面展示批量下载对话框，含文件格式、预估大小、取消与下载控件；保存页面没有展示实际下载响应。（读过官方页面（2026-10-20）；S2）
- 保存的检索页面文字未显示具体文件下载 URL 或文件下载端点；批量下载的请求形状与文件响应尚未验证。（仅读文档；S2）

## 2. 利用规约与署名

- e-Stat 利用规约将站点公开信息称为内容，并称可按六项规则复制、公衆送信及改编，且可商用；每项内容仍须核对规约适用范围及另行权利标记。（读过官方页面（2026-10-20）；S1）
- 该规约页面自述制定于 2016-01-29，并称遵循政府标准利用规约第 2.0 版；页面也称与 CC BY 4.0 兼容。（读过官方页面（2026-10-20）；S1）
- 页面要求使用内容时注明出处，并给出 e-Stat 门户和单项统计名称两类示例。（读过官方页面（2026-10-20）；S1）
- 编辑或加工内容时，页面要求在出处之外另行说明编辑或加工事实；页面还禁止将加工结果表述为由国家或府省制作。（读过官方页面（2026-10-20）；S1）
- 页面说明内容可能含第三方权利；除页面明确写明权利已处理的内容外，使用者须自行确认并取得所需许可。（读过官方页面（2026-10-20）；S1）
- 页面附件列出另有利用规则的项目，包括 API 功能；每份统计表文件是否受该页面规则覆盖，页面没有逐项确认。（读过官方页面（2026-10-20）；S1、S2）

## 3. 自动取得、负载与 robots

- 自动取得说明页将 API 与统计 LOD 列为自动取得统计数据的方式，没有说明统计表文件的自动下载方式。（读过官方页面（2026-10-20）；S3）
- 检索页显示批量下载对话框和预估大小，但没有给出文件下载的请求频率、每批上限或可供程序调用的文件下载端点。（读过官方页面（2026-10-20）；S2、S3）
- 已读文件路线页面没有公布每秒请求数或文件下载的速率数值；未将沉默解释为许可或上限。（仅读文档；S1-S3）
- www.e-stat.go.jp 的 robots 文本对 User-agent: * 禁止 /core/、/profiles/、/admin/、/search/ 等路径；保存文本没有列出 /stat-search/。（真实请求验证过；S5）
- robots 文本未列出 /stat-search/ 不能据此推断允许或禁止文件检索及下载。（仅读文档；S5）
- www.stat.go.jp 的 robots 文本只列出 /library/opac/ 的禁止规则；该主机与 e-Stat 检索主机不同，不能代替 e-Stat 主机的规则。（真实请求验证过；S5、S6）
- api.e-stat.go.jp 的 robots 请求得到 HTTP 404；404 响应不代表允许或禁止抓取。（真实请求验证过；S7）

## 4. 日期、更新与保存

- 检索页将提供周期、调查年月作为数据集一览的分组信息；保存页面没有展示可确认的单项文件日期字段或其定义。（读过官方页面（2026-10-20）；S2）
- 利用规约称内容可能不预告地变更、迁移或删除；已读页面没有给出文件保存期限或全站更新周期。（读过官方页面（2026-10-20）；S1-S3）
- 各表的实际调查期、公开日期、更新频率和旧版保留情况须以单项页面或文件再核实。（仅读文档；S1、S2）

## 5. 与 DATUMOJ 计划的对照

- 当前来源配置将 license.verified_at 留空，将 license.redistribution 记为 unverified，并把 usage_scope 设为 internal_only。（仅读文档；S1、S2）
- 当前配置的许可名称为政府标准利用规约第 2.0 版；e-Stat 利用规约页面称该页遵循此版本，但它自身的名称是 e-Stat 利用规约。（读过官方页面（2026-10-20）；S1）
- 对于规约适用的内容，页面文字写明可以复制与公衆送信，并称可以商用；但统计表文件逐项是否在范围内以及是否有第三方权利仍待确认。（读过官方页面（2026-10-20）；S1、S2）
- 配置中的出处写法没有 URL；页面给出的出处示例含 e-Stat 门户 URL，并要求编辑或加工时额外说明处理事实。（读过官方页面（2026-10-20）；S1）
- 当前配置的 rate_per_sec 为 0.5；已读文件路线页面未给出速率数值，不能把该设置写成门户公布的限制。（仅读文档；S1-S3）
- 当前配置的 max_total_bytes 为 1073741824、max_files 为 100；这些是配置值，已读页面没有确认它们是门户下载上限。（仅读文档；S1-S3）
- 当前配置的 schedule 为 monthly；检索页的提供周期与调查年月是分组维度，没有确认全站按月更新。（仅读文档；S2）
- 这些字段可据此核对。（仅读文档；S1-S3）
