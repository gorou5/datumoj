# 目标
全项目统一用总务省的地方公共团体代码表示地区，能从名称、代码、带或不带校验位的写法互相转换。

# 背景
旧项目没有地区码表，全是按用途写死，这次新建。代码表原始文件（总务省发布）由主对话放在 `tests/fixtures/area_codes/` 和 `src/datumoj/reference/data/`（如果还没有，本任务只用 fixture 测试并在 summary 里说明）。

计划见 `docs/PLAN.md`，任务总表见 `docs/TASKS.md`。
- 测试全部离线：不访问网络，HTTP 一律用 `tests/fixtures/` 里的录制样本或本地假服务器。
- 依赖已锁定在 `uv.lock`，不能新增依赖，也不能改 `pyproject.toml`。确实需要新依赖时，写进 `results/IVY-017/summary.md` 并停下来问。
- `tests/fixtures/` 下已有的样本只读；需要新样本就新建文件，并在该目录的 README.md 旁另写说明文件。
- 代码注释、docstring 用中文或英文均可；标识符用英文。

# 要求
1. `AreaCode`：6 位（含校验位）和 5 位互转；校验位算法按总务省规则实现并测试。
2. `lookup(name_or_code)`：支持“東京都”“東京”“13”“13000”“131016”；市区町村名同名时（如“府中市”）要求带上都道府县，否则返回多个候选而不是猜一个。
3. 都道府县 47 个代码固定；全国代码 `00000`。
4. 提供 `normalize_area_label(s)`：处理全角、空格、“都道府県名+市区町村名”拼在一起的写法。
5. 测试覆盖校验位、同名市、都道府县简称、无效代码。
