# 目标
Chunk 可以批量嵌入并存进 LanceDB，按向量检索；嵌入模型可替换，测试时用确定性的假模型。

# 背景
PLAN 4.2 和第 13 节决定：默认 bge-m3 通过本机 Ollama 运行，向量库用 LanceDB。真实模型的效果比较由人在主对话里做（见 `docs/TASKS.md` H5）。

计划见 `docs/PLAN.md`，任务总表见 `docs/TASKS.md`。
- 测试全部离线：不访问网络，HTTP 一律用 `tests/fixtures/` 里的录制样本或本地假服务器。
- 依赖已锁定在 `uv.lock`，不能新增依赖，也不能改 `pyproject.toml`。确实需要新依赖时，写进 `results/IVY-023/summary.md` 并停下来问。
- `tests/fixtures/` 下已有的样本只读；需要新样本就新建文件，并在该目录的 README.md 旁另写说明文件。
- 代码注释、docstring 用中文或英文均可；标识符用英文。

# 要求
1. `Embedder` 协议：`dim`、`name`、`embed(texts) -> list[list[float]]`。实现：`OllamaEmbedder(model, base_url)`（httpx 调 `/api/embed`，批量、超时、重试）和 `HashEmbedder`（测试用，确定性）。
2. `VectorIndex(path, embedder)`：`add(chunks)`（只嵌入新的或文本变了的块，按 `chunk_id` + 文本哈希判断）、`search(query, k, source_ids=None)`、`delete(doc_key)`；索引里记录模型名和维度，换模型时拒绝混用并提示重建。
3. 批处理和断点：中途失败重跑时跳过已完成的块。
4. 测试只用 `HashEmbedder` 和本地假 Ollama 服务（不联网）：增量、换模型拒绝、过滤、删除。
