# 目标
气象厅防灾信息 XML 的长期 feed 能每小时轮询，新条目的 XML 都保存下来，并转成可检索的文本块。

# 背景
长期 feed（`extra_l.xml`、`regular_l.xml` 等）每小时更新，只保留约 7 天，所以要尽早开始持续轮询（PLAN 第 12 节）。样本在 `tests/fixtures/jma/`（含旧项目的 `jma-osaka-forecast-20261015.xml`）。

计划见 `docs/PLAN.md`，任务总表见 `docs/TASKS.md`。
- 测试全部离线：不访问网络，HTTP 一律用 `tests/fixtures/` 里的录制样本或本地假服务器。
- 依赖已锁定在 `uv.lock`，不能新增依赖，也不能改 `pyproject.toml`。确实需要新依赖时，写进 `results/IVY-021/summary.md` 并停下来问。
- `tests/fixtures/` 下已有的样本只读；需要新样本就新建文件，并在该目录的 README.md 旁另写说明文件。
- 代码注释、docstring 用中文或英文均可；标识符用英文。

# 要求
1. 解析 Atom feed，按 entry id 去重，只抓新条目；feed 本身也存快照。
2. 条目 XML 用安全 XML 解析（同 IVY-008 的原则）；可选字段（如 `Duration`）缺失时不报错（旧项目踩过）。
3. 每个条目转成一个 Document：标题、发表时间、发表官署、对象地区、正文文本；locator 为 `entry=<entry id>`；`published_at` 必填。
4. `sources/jp-jma.yaml` 的 `schedule` 设为每小时；`scope.feeds` 列出要轮询的 feed。
5. 测试：去重、新条目识别、可选字段缺失、恶意 XML 被拒。

- 不抓平年值（以后再做）。
