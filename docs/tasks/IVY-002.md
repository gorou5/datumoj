# 目标
原始字节按 sha256 存进 `data/raw/<前两位>/<sha256>`，同样内容只存一份，读出时可校验。

# 背景
PLAN 4.1：派生数据都能从 raw 重新生成，所以 raw 必须不可变、可校验。

计划见 `docs/PLAN.md`，任务总表见 `docs/TASKS.md`。
- 测试全部离线：不访问网络，HTTP 一律用 `tests/fixtures/` 里的录制样本或本地假服务器。
- 依赖已锁定在 `uv.lock`，不能新增依赖，也不能改 `pyproject.toml`。确实需要新依赖时，写进 `results/IVY-002/summary.md` 并停下来问。
- `tests/fixtures/` 下已有的样本只读；需要新样本就新建文件，并在该目录的 README.md 旁另写说明文件。
- 代码注释、docstring 用中文或英文均可；标识符用英文。

# 要求
1. `RawStore(root)`：`put(bytes 或 流) -> sha256`、`get(sha256) -> bytes`、`open(sha256)`（流式读）、`exists(sha256)`、`verify(sha256)`、`path_for(sha256)`。
2. 写入先写临时文件再原子 rename；重复写入相同内容不报错、不改文件。
3. 大文件流式写入，不一次读进内存（测试用 >10MB 的生成数据验证峰值不需要整块读）。
4. 存好的文件设为只读权限；`verify` 发现内容和文件名哈希不一致时报 `CorruptedBlob`。
5. 根目录由参数或环境变量 `DATUMOJ_DATA_DIR` 决定（默认 `./data`），测试用 `tmp_path`。

# 不做
- 不管 manifest，不管 HTTP。
- 不做压缩、不做远程存储。
