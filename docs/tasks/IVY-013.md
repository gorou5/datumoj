# 目标
有 20 道法令检索题，在固定的小语料上 Recall@10 ≥ 0.85，作为之后改检索时的回归基线。

# 背景
小语料由 `tests/fixtures/egov_law/` 里的法令样本构成（只能用已有样本，不能联网）。题目参考交接包 `handoff/digital-assets-20261020/06_后续工作与验收.md` 的问法。

计划见 `docs/PLAN.md`，任务总表见 `docs/TASKS.md`。
- 测试全部离线：不访问网络，HTTP 一律用 `tests/fixtures/` 里的录制样本或本地假服务器。
- 依赖已锁定在 `uv.lock`，不能新增依赖，也不能改 `pyproject.toml`。确实需要新依赖时，写进 `results/IVY-013/summary.md` 并停下来问。
- `tests/fixtures/` 下已有的样本只读；需要新样本就新建文件，并在该目录的 README.md 旁另写说明文件。
- 代码注释、docstring 用中文或英文均可；标识符用英文。

# 要求
1. 20 道题全部是 `retrieval` 类：至少 12 道日文、4 道中文、4 道英文；中文和英文题必须在 `queries` 里给出改写后的日文查询（模拟宿主模型改写），同时保留原文。
2. 每道题的期望命中写到条（`doc_key` + `art=`），并在 `notes` 里写一句为什么是这一条。
3. 问法要像真实用户：例如“個人情報を第三者に提供するときに本人の同意が要らない場合は？”，不要直接照抄条文原句。
4. `tests/eval/test_law_eval.py`：用 fixture 构建临时索引（走 IVY-010 流水线），跑 `run_eval`，断言 Recall@10 ≥ 0.85，并把报告写到临时目录。
5. 不能为了达标去改检索代码；达不到就如实报告哪些题没命中，写进 `results/IVY-013/summary.md`。
