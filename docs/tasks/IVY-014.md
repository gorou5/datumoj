4. 许可分数据集和资源两级，原样保存，不做推断。
5. 注册 kind `ckan`，写 `sources/jp-egov-data.yaml`。
6. 测试：分页、增量、白名单过滤、单个资源 404 不影响整体、许可字段缺失或矛盾时原样保留。
