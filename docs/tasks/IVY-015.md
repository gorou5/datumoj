# 目标
CKAN 数据集元数据进入 `catalog` 表，可以按关键词、组织、格式、更新时间检索到数据集和资源。

# 背景
PLAN 2：用户要先能“找到有哪些数据”。目录检索和正文检索分开，回答时要区分“目录查到”和“正文已读到”。

计划见 `docs/PLAN.md`，任务总表见 `docs/TASKS.md`。
- 测试全部离线：不访问网络，HTTP 一律用 `tests/fixtures/` 里的录制样本或本地假服务器。
- 依赖已锁定在 `uv.lock`，不能新增依赖，也不能改 `pyproject.toml`。确实需要新依赖时，写进 `results/IVY-015/summary.md` 并停下来问。
- `tests/fixtures/` 下已有的样本只读；需要新样本就新建文件，并在该目录的 README.md 旁另写说明文件。
- 代码注释、docstring 用中文或英文均可；标识符用英文。

# 要求
1. `ckan_meta.py`：把 package JSON 转成 `Dataset` + `Resource` 记录（标题、说明、标签、组织、地区、更新频率、两级许可、资源格式和 URL、是否已下载及快照）。
2. `CatalogStore`：SQLite 表，`upsert`、按 `dataset_id` 取、列出资源及其下载状态。
3. `search_catalog(query, filters, k)`：FTS5 trigram 检索标题、说明、标签；过滤器支持来源、组织、格式、更新时间范围；结果标注每个资源是“仅目录”还是“已抓取正文”。
4. 在 `src/datumoj/parsers/registry.py` 登记 CKAN 元数据解析器，让 IVY-010 的流水线能处理 `ckan` 来源的快照。
5. 测试用 fixture 里的 package JSON 覆盖：转换、检索、过滤、状态标注。

# 不做
- 不解析资源内容。
