# 目标
MCP 和 CLI 共用的一组纯函数工具，输入输出都是可序列化的 dict，每个结果都带出处，并把来源正文标注为“数据”。

# 背景
PLAN 4.3。MCP 服务器（IVY-026）只是把这些函数包一层。

计划见 `docs/PLAN.md`，任务总表见 `docs/TASKS.md`。
- 测试全部离线：不访问网络，HTTP 一律用 `tests/fixtures/` 里的录制样本或本地假服务器。
- 依赖已锁定在 `uv.lock`，不能新增依赖，也不能改 `pyproject.toml`。确实需要新依赖时，写进 `results/IVY-025/summary.md` 并停下来问。
- `tests/fixtures/` 下已有的样本只读；需要新样本就新建文件，并在该目录的 README.md 旁另写说明文件。
- 代码注释、docstring 用中文或英文均可；标识符用英文。

# 要求
1. `search_docs(queries, k=10, sources=None, since=None)`：调 IVY-024，返回块摘要、出处、`gap_state`、各来源新鲜度。
2. `search_catalog(query, filters)`：调 IVY-015，标注“仅目录 / 已抓取正文 / 已入观测值库”。
3. `query_sql(sql)`：调 IVY-018 的只读查询，附 `describe()` 的简要说明和出处。
4. `get_chunk(chunk_id, context=1)`：返回该块全文和前后各 N 块。
5. `cite(snapshot_sha256, locator)`：回到 raw 快照，重新定位并返回原文片段，用于核对引用；定位不到时明确返回 `not_found`。
6. `version()`：包版本、git 提交、数据目录、各索引的构建时间（用于验收时核对宿主加载的是不是新版本，PLAN 第 12 节）。
7. `glossary.yaml` + `expand_terms(query)`：中英常用政务词到日文的对照（如 个人信息→個人情報、补贴→補助金、startup→スタートアップ），作为宿主模型改写查询的补充，**不调用任何 LLM**。先放 100 条左右。
8. 所有来源文本放在 `content` 字段，并带 `content_role: "untrusted_source_text"`；工具输出里不能把来源文本拼进说明性字段。
9. 测试覆盖每个工具的正常、空结果、错误输入，以及 `cite` 能还原 IVY-013 语料里的条文。

- 不写 MCP 协议层。
