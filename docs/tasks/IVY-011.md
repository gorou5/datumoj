# 目标
人可以在终端用 `datumoj` 命令完成抓取、解析、建索引、检索，并看到带出处的结果。

# 背景
M1 的人工验收就是用这个命令演示（PLAN 第 8 节）。入口在 `pyproject.toml` 里已登记为 `datumoj = "datumoj.cli:app"`。

计划见 `docs/PLAN.md`，任务总表见 `docs/TASKS.md`。
- 测试全部离线：不访问网络，HTTP 一律用 `tests/fixtures/` 里的录制样本或本地假服务器。
- 依赖已锁定在 `uv.lock`，不能新增依赖，也不能改 `pyproject.toml`。确实需要新依赖时，写进 `results/IVY-011/summary.md` 并停下来问。
- `tests/fixtures/` 下已有的样本只读；需要新样本就新建文件，并在该目录的 README.md 旁另写说明文件。
- 代码注释、docstring 用中文或英文均可；标识符用英文。

# 要求
1. 用 typer。命令：`crawl SOURCE [--limit N] [--dry-run]`、`parse [SOURCE]`、`index [--rebuild]`、`search QUERY [-k 10] [--source ...] [--json]`、`status`（每个来源：快照数、最后成功时间、失败数、chunk 数）。
2. 数据目录默认 `./data`，可用 `--data-dir` 或 `DATUMOJ_DATA_DIR` 覆盖。
3. `search` 的人读输出：每条结果一行标题路径 + locator，一行摘要，一行出处（`Citation.render()`）；`--json` 输出结构化结果。
4. 检索零命中时明确输出“零命中”，并提示当前索引里有哪些来源。
5. 退出码：成功 0，参数错误 2，运行失败 1。
6. 测试用 typer 的 CliRunner 和回放客户端（注入方式由你设计，不能联网）跑通 crawl→parse→index→search 全流程。
