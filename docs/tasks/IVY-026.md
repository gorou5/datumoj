用 `mcp` Python SDK（FastMCP）。工具实现全部在 IVY-025，这里只做协议包装。

计划见 `docs/PLAN.md`，任务总表见 `docs/TASKS.md`。
- 测试全部离线：不访问网络，HTTP 一律用 `tests/fixtures/` 里的录制样本或本地假服务器。
- 依赖已锁定在 `uv.lock`，不能新增依赖，也不能改 `pyproject.toml`。确实需要新依赖时，写进 `results/IVY-026/summary.md` 并停下来问。

1. 暴露工具：`search_docs`、`search_catalog`、`query_sql`、`get_chunk`、`cite`、`version`、`coverage`（列出全部来源、状态和新鲜度）。每个工具的描述用英文写清用途、参数、限制（比如“数值只能用 query_sql”）。
