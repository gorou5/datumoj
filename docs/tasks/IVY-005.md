# 目标
所有解析器共用一套日文处理：解码、归一化、和历转换、数字解析。

# 背景
政府数据里全角数字、和历（令和/平成/昭和）、cp932 文件非常多。旧项目踩过：响应头写 UTF-8 实际是 cp932。PLAN 第 9 节“踩过的坑”。

计划见 `docs/PLAN.md`，任务总表见 `docs/TASKS.md`。
- 测试全部离线：不访问网络，HTTP 一律用 `tests/fixtures/` 里的录制样本或本地假服务器。
- 依赖已锁定在 `uv.lock`，不能新增依赖，也不能改 `pyproject.toml`。确实需要新依赖时，写进 `results/IVY-005/summary.md` 并停下来问。
- `tests/fixtures/` 下已有的样本只读；需要新样本就新建文件，并在该目录的 README.md 旁另写说明文件。
- 代码注释、docstring 用中文或英文均可；标识符用英文。

# 要求
1. `decode_bytes(data, declared=None) -> (text, encoding)`：识别 BOM、UTF-8、cp932/Shift_JIS、EUC-JP；声明的编码解码失败时要退回探测，并在返回值里标记“声明不符”。
2. `normalize(text)`：NFKC、统一空白、去掉零宽字符；**不改变**“〇”“−”这类在数值里有含义的字符的识别能力（另有 `parse_number` 处理）。
3. `parse_number(s)`：支持全角数字、千分位、`△`/`▲` 表示负数、`-`/`…`/`x`/`X`/`秘匿`/`－` 等注记返回 `(None, note)`。
4. `wareki_to_date` / `wareki_year`：令和、平成、昭和、大正，含“元年”、全角数字、漢数字（如“令和六年”）、只到年或年月的情况；年度（`令和5年度`）返回年度标记。
5. `kansuji_to_int`：处理“第二十七条”“百二十三”这类法令编号。
6. 测试用参数化用例覆盖每个函数，至少 60 个用例，包括错误输入。
