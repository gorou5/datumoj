# 目标
离线评测覆盖所有确定性的指标，并能用 `datumoj eval --gate` 一条命令判断是否达标。

# 背景
PLAN 第 10 节的门槛：Recall@10 ≥ 0.85；数值精确 100%；缺口状态正确率 100%；引用可还原率 ≥ 0.95。

计划见 `docs/PLAN.md`，任务总表见 `docs/TASKS.md`。
- 测试全部离线：不访问网络，HTTP 一律用 `tests/fixtures/` 里的录制样本或本地假服务器。
- 依赖已锁定在 `uv.lock`，不能新增依赖，也不能改 `pyproject.toml`。确实需要新依赖时，写进 `results/IVY-027/summary.md` 并停下来问。
- `tests/fixtures/` 下已有的样本只读；需要新样本就新建文件，并在该目录的 README.md 旁另写说明文件。
- 代码注释、docstring 用中文或英文均可；标识符用英文。

# 要求
1. 评测改用 IVY-025 的工具函数作为被测对象（`search_docs` 用题目里的 `queries`）。
2. `gap` 类：比较 `gap_state`；`time` 类：检查返回的出处带有统计期间或发布日；`injection` 类：检查注入文本只出现在 `content` 字段。
3. 引用可还原率：对每道题检索结果的前 3 条调用 `cite`，统计能还原的比例。
4. `datumoj eval [--gate] [--report DIR]`：门槛不达标时退出码 1。
5. 测试覆盖每类指标的计算和门槛判断。
