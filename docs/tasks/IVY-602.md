# 目标
人可以在终端用 `datumoj` 完成抓取、解析、建索引、检索和查询，结果带出处。

# 背景
开发线：F 入口线。入口已在 `pyproject.toml` 登记为 `datumoj = "datumoj.cli:app"`。`wiring.py` 负责把各协议接上实现：真实实现存在就用真实的，测试里可以注入假实现。

计划见 `docs/PLAN.md`，任务总表、开发线和跨任务约定见 `docs/TASKS.md`。
- **只依赖契约**：数据模型在 `src/datumoj/core/models.py`，接口协议和插件发现在 `src/datumoj/core/contracts.py`，假实现和契约测试在 `src/datumoj/testing/`。不要 import 其他开发线的实现模块（集成任务除外）。
- 测试全部离线：不访问网络，HTTP 一律用 `tests/fixtures/` 里的录制样本或本地假服务器。
- 依赖已锁定在 `uv.lock`，不能新增依赖，也不能改 `pyproject.toml`。确实需要时写进 `results/IVY-602/summary.md` 并停下来问。
- `tests/fixtures/` 下已有的样本只读；需要新样本就新建文件。
- 需要改契约（models.py、contracts.py）时不要自己改，写进 summary 并停下来问。

# 要求
1. typer 命令：`crawl SOURCE [--limit] [--dry-run]`、`parse [SOURCE]`、`index [--rebuild]`、`search QUERY... [-k] [--source] [--json]`、`sql QUERY [--json]`、`status`。
2. `wiring.build(data_dir, overrides=None)`：按协议组装依赖；某个真实实现还不存在（导入失败）时，命令报“该功能尚未接入”，不崩溃。
3. `search` 人读输出：标题路径 + locator、摘要、出处；零命中时说明零命中和当前有哪些来源。
4. 退出码：成功 0、参数错误 2、运行失败 1。
5. 测试用 CliRunner 和注入的假实现跑通全部命令。
