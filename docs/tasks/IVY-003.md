# 目标
所有采集器共用一个“对政府站点礼貌”的 HTTP 客户端，测试时可以无网络回放录制样本。

# 背景
参考旧项目 `/Users/aaron/codex_workspace/digital-assets/repo/plugin-prototype/runtime/src/adapters/http-readonly.ts` 的安全设计（只读、重定向逐跳校验、容量与时长预算），本任务再补上限速和重试。PLAN 第 5 节“抓取守则”。

计划见 `docs/PLAN.md`，任务总表见 `docs/TASKS.md`。
- 测试全部离线：不访问网络，HTTP 一律用 `tests/fixtures/` 里的录制样本或本地假服务器。
- 依赖已锁定在 `uv.lock`，不能新增依赖，也不能改 `pyproject.toml`。确实需要新依赖时，写进 `results/IVY-003/summary.md` 并停下来问。
- `tests/fixtures/` 下已有的样本只读；需要新样本就新建文件，并在该目录的 README.md 旁另写说明文件。
- 代码注释、docstring 用中文或英文均可；标识符用英文。

# 要求
1. 基于 httpx 同步客户端。`PoliteClient(user_agent, rate_per_host, max_bytes, timeout, allowed_hosts)`；`fetch(url, etag=None, last_modified=None) -> FetchResult`（状态、headers、body 或临时文件路径、`outcome`、耗时、最终 URL）。
2. 按 host 限速（默认 1 请求/秒，可配置），用可注入的时钟以便测试不真的 sleep。
3. 条件请求：带上 `If-None-Match` / `If-Modified-Since`，304 返回 `outcome=not_modified`。
4. 429/5xx/网络错误按指数退避重试，次数有上限；尊重 `Retry-After`；4xx（除 429）不重试。
5. 响应超过 `max_bytes` 立即中止，`outcome=too_large`；不能先整块下载再判断。
6. 重定向逐跳检查：只允许 http/https、目标 host 在 `allowed_hosts`（支持 `*.go.jp` 这类后缀）里，拒绝私网和回环地址。
7. 请求了 identity 编码但服务器仍返回 gzip 时，要正确解压（旧项目在巴西 IBGE 踩过）。
8. 日志、异常信息、`FetchResult` 里的 URL 一律去掉 Key（复用 IVY-001 的去 Key 函数）。
9. robots.txt：提供 `RobotsCache`，按 host 缓存，`fetch` 前检查，被禁止时 `outcome=blocked_by_robots`，不发请求。
10. 回放：`ReplayTransport(mapping)`，把 URL（忽略 Key 参数、参数顺序无关）映射到 fixture 文件和状态码；未登记的 URL 直接报错，保证测试不会悄悄联网。
11. 测试用 pytest-httpserver 起本地假服务器或用 `httpx.MockTransport`，覆盖以上每一条。
