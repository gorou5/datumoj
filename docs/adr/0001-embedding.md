# ADR 0001：嵌入模型与向量相似度阈值

- 状态：已采纳（2026-10-21，H5）
- 相关：PLAN 第 4.2 节、第 13 节第 2 条；DATUMOJ-IVY-502、503、505、607

## 决定

1. 嵌入模型用 **bge-m3**，通过本机 Ollama 运行（`OllamaEmbedder` 的默认值）。
2. 混合检索的向量相似度阈值**按模型取值**：bge-m3 为 **0.6**，其他模型（含测试用的 `HashEmbedder`）为 0.3。见 `src/datumoj/index/hybrid.py` 的 `MIN_VECTOR_SCORE_BY_MODEL`；调用方显式传入 `min_vector_score` 时以传入值为准。
3. 向量是可选的：没有模型或连接失败时退回纯关键词检索（607），`DATUMOJ_VECTORS=off` 可以直接关闭。

## 依据

在 903 的完整评测语料上（83 份快照：22 部法令、Dashboard、e-Stat、CKAN、JMA、注入样本；60 题），用真实 bge-m3 建索引（解析 83 份，0 失败，用时约 2 分钟），比较纯关键词与不同阈值的混合检索：

| 检索方式 | Recall@10 | MRR | 缺口正确率 | 默认门槛 |
|---|---:|---:|---:|---|
| 纯关键词 | 0.962 | 0.850 | 1.000 | 通过 |
| 混合，阈值 0.0 / 0.3 / 0.4 | 0.962 | 0.854 | **0.875** | **不通过** |
| 混合，阈值 0.5 / 0.55 / 0.6 | 0.962 | 0.854 | 1.000 | 通过 |
| 混合，阈值 0.65 | 0.962 | 0.874 | 1.000 | 通过 |
| 混合，阈值 0.7 | 0.962 | 0.862 | 1.000 | 通过 |

各题向量最高分：
- 应判“零命中”的无关问题（问木星地表积雪量）最高 **0.471**；阈值低于它时被误判为有命中。
- 真正相关的 20 道检索题最低 **0.685**，中位数 0.747。

所以取 **0.6**，两边各留约 0.1 的余量。0.65 的 MRR 略高，但离相关题的下限只有 0.035，余量太小。

## 观察与遗留

- 在这份语料上，混合检索的召回率和纯关键词**一样**（0.962），只把 MRR 提高了一点。语料小（22 部现代法令），词面重合度高，关键词已经够用；向量的价值要在更大、更多样的真实语料上（例如全量法令、政策网页）再评估。
- 两道题在任何配置下都失败：e-Stat 解析器只产出观测值，不产出可检索的文档或数据集条目，所以 e-Stat 表在文档检索和目录检索里都找不到（数值本身用 SQL 能算对、出处能还原）。这是 IVY 之后的改进项。
- PLAN 原计划在全量法令（约 100 万块）上测两个字以下短查询（LIKE 全表扫描）的耗时。目前真实语料只有 200 部法令、11,277 个块，测不出全量规模下的表现，留到全量抓取时再测。
- 结论依赖评测题的覆盖面；评测题扩充后应重跑本对比（脚本思路：复用 `tests/integration/test_full_eval.py` 的语料搭建，换成真实 `OllamaEmbedder`，对不同阈值分别跑 `evaluate`）。
