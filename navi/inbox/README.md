# inbox — 协作者同步目录

Datumoj 的协作者把自己的任何近况同步到这里：进展、决定、问题、产出链接，都行。

## 怎么放

- 在本目录（`navi/inbox/`）新建一个文件，**格式不限，Markdown 或 HTML 优先**（.md / .html / .txt 都收）。
- 文件名建议：`YYYY-MM-DD-你的名字-主题.md`，例如 `2026-10-26-gorou5-plan-v05.md`。
- 一个文件说一件事，写清日期和你是谁；内容真实即可，不用排版。

## 会发生什么

- 每天定时检查本目录：新文件的要点会被核实后写进 navi.datumoj.com 首页的「最新动态」，注明来源文件。
- 处理完的文件移入 `archive/` 子目录归档（原文件名不变），本目录只留未处理的新文件。
- 没有新文件就不产生动态——不编造、不凑数。
