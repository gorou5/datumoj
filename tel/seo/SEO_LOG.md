# tel.datumoj.com SEO 監視・改善ログ

目的：在日生活者が、広告や誤情報に邪魔されず、電話番号の素性（種類・地域・事業者）を公的データで素早く確認できるよう、対象番号クエリで tel.datumoj.com を Google 上位に育てる。**手法は白帽のみ**（後述の禁止事項参照）。

## 対象クエリ（4件＝2番号×2表記）
- `0800-777-9633` / `08007779633`（フリーダイヤル0800、割当事業者 KDDI＝総務省指定データ）
- `0120-923-499` / `0120923499`（フリーダイヤル0120、割当事業者 KDDI＝同上）

## 測定口径
- Google（google.co.jp 系、未ログイン・パーソナライズなし相当）で素の番号そのものを検索し、tel.datumoj.com の順位を記録する。順位は測定ごとに揺れるため、単発の数字ではなく推移で判断する。
- 本物の順位データ（表示回数・CTR）は Google Search Console が必要（オーナーの Google アカウントでの所有権確認待ち。それまでは検索実測を代理指標とする）。

## 禁止事項（白帽の線引き）
- キーワード詰め込み、隠しテキスト、クローキング、リンク購入・相互リンク集への参加、自動生成の口コミ・報告の捏造、他社の事業者情報の無断複製は行わない。
- 事業者情報（business_registration）への登録は、公式サイト等で確認できる出典がある場合のみ。
- URL 構造の変更・ページ削除など不可逆な変更は実施せず、必要なら本ログに「要承認」として記録しユーザーの判断を待つ。

## 改善バックログ（優先順）
1. [済] 対象ページの index 解放＋sitemap 掲載（第1ラウンド）
2. [済] 番号ページに FAQ（可視コンテンツ＋FAQPage 構造化データ）（第1ラウンド）
3. [一部済・第2ラウンド] 内部リンク強化：種類ページ（/type/free0800・/type/free0120）から対象番号への導線は設置済み。ホームの「よく調べられている番号」枠は view カウンタの実データ待ちのため未実施
4. タイトル・説明文の磨き込み（検索意図「誰から／迷惑電話か」への正直な回答範囲で）
5. ページ表示速度・モバイル体験の監査（Core Web Vitals）
6. Search Console 所有権確認（ユーザー作業）→ 実データで対象を拡張
7. 対象番号の周辺区画ページ（近い番号）の内部リンク密度向上
8. /history・/about など信頼ページからの内部リンクと E-E-A-T 補強（出典明示の徹底）

### 2026-10-22 18:16 第2ラウンド（実施）
- **測定**：Google 順位の実測を試行したが、クラウドブラウザが Google の bot 検知（sorry/index ページ）にブロックされ、4クエリ（0800-777-9633／08007779633／0120-923-499／0120923499）とも順位取得不可。google.co.jp と google.com の両方でブロック、bot チェックを突破できず測定を断念。前回の既知状態は未掲載（第0ラウンド）。第1ラウンドで index 解放済みだが、その効果の初回測定は未実施のまま。
- **重大な発見（本ラウンドの主成果）**：本番 tel.datumoj.com の D1 連動ルート（番号ページ全件・/type/*・/sitemap.xml）がすべて **HTTP 500** を返している。ホーム（/）と /robots.txt は 200 で正常。wrangler で D1 を直接叩いたところ **「Your account has exceeded D1's free tier daily row read limit」[code: 7500]** を確認——午前に枯渇した書き込み上限に続き、読み取り上限も使い切った。回復は UTC 午夜＝**JST 10-23 09:00** の見込み。回復まで Googlebot が来ても 500 を返すため、対象ページのインデックス化は進まない（クロールされれば de-index の恐れあり）。これは SEO 施策以前の問題であり、次回以降のラウンドでも 10-23 09:00 までは測定・効果確認ができない。
- **実施施策**（バックログ3「内部リンク強化」から1件のみ。測定不能のため前回既知状態＝未掲載を前提に、予定どおり次順位の項目を実施）：種類ハブ `/type/free0800`・`/type/free0120` に「番号の例」カードを追加し、対象番号ページ（/08007779633・/0120923499）への内部リンクを設置（render.js の FEATURED_NUMBERS。白帽範囲内、既存の Tier 1 実データページへのリンクのみ）。ホームの「よく調べられている番号」枠は view カウンタの実データがまだ無いため今回は見送り（バックログ3は一部済として残す）。
- **デプロイ**：node --check 通過 → wrangler deploy 成功（Version f1634b5e）→ 変更 URL（/type/free0800・/type/free0120）のキャッシュ purge 成功。curl 実測は D1 枯渇のため 500（想定内・回復後に再確認）。レンダー自体はモック hub によるローカル検証済み（free0800/free0120 に正しいリンク、他種類にはカード非表示）。
- **次回確認すべき効果**：① D1 回復後に対象ページ・種類ハブ・sitemap が 200 で返ること ② Google 順位の初回取得（未掲載→掲載の有無と初期順位）③ 種類ハブからの内部リンクの効果。※ Google bot 検知が続く場合は測定口径の代替手段を検討要。
